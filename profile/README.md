## Philosophy

Every package in this organization follows the same principles:

- **Focused** — does one thing and does it well
- **Tested** — full test coverage across supported PHP and Laravel versions
- **Maintained** — kept up to date with each new Laravel major release
- **Simple API** — no unnecessary configuration, works out of the box
